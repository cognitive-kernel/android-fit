# فیت‌یار (Android Fit)

اپلیکیشن اندروید آفلاین برای ساخت برنامه‌های تمرینی، ثبت اجرای تمرین، قدم‌شمار و خروجی CSV. داده‌ها با SQLite روی دستگاه ذخیره می‌شوند.

## پیش‌نیازها
- Android Studio و JDK 17
- Android SDK Platform 35
- Android Gradle Plugin 8.7.3 و Gradle 8.9

## اجرا و تست
مخزن را در Android Studio باز کنید و Gradle Sync را انجام دهید. تست‌های واحد را از بخش verification اجرا کنید. برای ساخت APK از Build > Build APK(s) استفاده کنید.

GitHub Actions با هر push به شاخه main تست‌های واحد را اجرا می‌کند، APK دیباگ را می‌سازد و آن را به‌عنوان artifact نگه می‌دارد. فایل APK در صفحه Actions و اجرای موفق workflow قابل دریافت است.

## قابلیت‌ها
- ساخت و حذف برنامه تمرینی و افزودن، ویرایش یا حذف حرکات
- ثبت تاریخ شمسی، حرکت، ست، تکرار و وزن
- ذخیره محلی SQLite و خروجی CSV از سوابق
- قدم‌شمار با حسگر سخت‌افزاری پشتیبانی‌شده

تاریخ با DatePicker اندروید انتخاب و سپس به تاریخ شمسی تبدیل می‌شود. تا پیش از اجرای موفق CI، ساخت و اجرای پروژه تأییدشده محسوب نمی‌شود.

## نسخه‌ها و امضای APK (مهم برای به‌روزرسانی)

- شناسهٔ بستهٔ برنامه باید همیشه `com.cognitivekernel.androidfit` بماند.
- برای هر انتشار، `versionCode` باید افزایش یابد و `versionName` متناسب با نسخه به‌روزرسانی شود.
- APKهای CI با کلید debug پایدار ذخیره‌شده در GitHub Actions Cache با کلید `fit-yar-debug-signing-key-v1` ساخته می‌شوند. این کلید را حذف، بازتولید یا با کلید دیگری جایگزین نکنید؛ در غیر این صورت نصب به‌روزرسانی روی نسخهٔ موجود ممکن است به خطای امضا منجر شود.
- workflow پیش از ساخت، وجود کلید را بررسی می‌کند و اثرانگشت گواهی را در لاگ ثبت می‌کند تا تغییر ناخواسته قابل تشخیص باشد.
- نخستین APK که با این سیاست ساخته شده، ممکن است با APKهای قدیمیِ امضاشده با کلید دیگری سازگار نباشد. پس از انتقال یک‌باره به کلید پایدار، از این پس همهٔ APKهای CI باید با همان کلید ساخته شوند.
- فایل APK را از artifact همان اجرای موفق CI دریافت کنید؛ ساخت محلی یا ساخت از workflow دیگری که این کلید را ندارد ممکن است امضای متفاوت تولید کند.
