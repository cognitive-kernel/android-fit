# FitYar 1.1.8 — نامزد یادداشت انتشار

> وضعیت: پیش‌نویس داخلی؛ این نسخه تا تکمیل CI، آزمون‌های دستی و تأیید امضای سازگار برای انتشار یا نصب روی نسخهٔ موجود تأیید نشده است.

## تغییرات نامزد

- برنامه‌ریزی تمرین برای کاهش وزن، فیتنس و عضله‌سازی با انتخاب ناحیهٔ عضلانی.
- ثبت جزئیات تمرین شامل استراحت، RPE و یادداشت.
- تاریخچه و نمودار پیشرفت تمرین، ثبت خواب، علائم حیاتی و اندازه‌گیری‌های بدن.
- قدم‌شمار پس‌زمینه با کنترل شروع، مکث و پایان، با حفظ وضعیت مکث پس از راه‌اندازی مجدد.
- خروجی CSV با UTF-8، کوتیشن‌گذاری و خنثی‌سازی مقادیر شبیه فرمول صفحه‌گسترده.
- پشتیبان‌گیری انتخابی JSON برای سوابق تمرین، سلامت، قدم‌شمار و تنظیمات.
- بازیابی انتخابی که بخش‌های انتخاب‌شده را جایگزین می‌کند و سایر بخش‌ها را حفظ می‌کند.
- محدودیت اندازهٔ ۲۵ مگابایت برای فایل پشتیبان، رد بخش‌های تکراری و تأیید جداگانه پیش از جایگزینی کل پایگاه داده از فایل SQLite قدیمی.
- گسترش آزمون‌های خودکار برای اعتبارسنجی داده، مهاجرت پایگاه داده و پشتیبان‌گیری انتخابی.

## نکات مهم پیش از انتشار

- آزمون‌های CI باید روی آخرین commit موفق شوند؛ نتیجهٔ اجرای قبلی به commitهای بعدی تعمیم داده نمی‌شود.
- بازیابی واقعی پشتیبان و رفتار روی گوشی واقعی هنوز باید بررسی شود.
- APK آزمایشی با شناسهٔ بستهٔ جداگانه، جایگزین نسخهٔ نصب‌شده نیست.
- انتشار APK اصلی تا بازیابی و تأیید کلید خصوصی سازگار متوقف می‌ماند. برنامهٔ نصب‌شده را برای دور زدن اختلاف امضا حذف نکنید.
- این پیش‌نویس تا زمان تأیید تمام موارد بالا، یادداشت انتشار عمومی محسوب نمی‌شود.
